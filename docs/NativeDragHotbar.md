# 拖放热键栏 1.0.0

作者：Yuzi。模块身份 `NativeDragHotbar`，API 1，最低 Omni 1.1.8.9；程序集与文件版本为 1.0.0.0，运行环境为 .NET 10 / Windows x64。

## 简介

支持直接拖入游戏原生技能、通用技能、物品、情感动作、功能按钮、用户宏及套装，并可右键编辑，在原生动作后追加自定义指令。支持自填“横向 × 纵向”布局，每栏最多 120 格、最多 12 栏；可调整缩放、不透明度、隐藏空格，悬浮窗跟随 Omni 主题，并支持剪贴板导入导出。

这是独立模块，与原有 `CustomHotbar` 使用不同身份及配置格式，不替换原模块，也不自动读取其配置。该 DLL 与此前已发布的 NativeDragHotbar 1.0.0 为同一文件，版本未重用为不同内容。

## 安装与操作

在 Omni 在线模块中添加本仓库，刷新清单并安装“拖放热键栏”，首次安装后手动启用。

```text
https://github.com/wuyujindu/OmniToolbox.TreeHouseOnline
```

1. 登录角色，在模块设置中新增热键栏，填写横向与纵向格数，点击“应用布局”。
2. 从游戏技能、功能、背包或原生热键栏拖入格子；左键点击执行，右键打开指令编辑窗口。
3. 切换为自定义指令时保留已拖入的原生动作，可继续追加指令。指令编辑框也可通过拖入追加游戏原生名称或情感动作指令。
4. 未锁定时可在栏内拖动格子换位；游戏原生热键栏锁定后仍可拖入，禁止栏内换位和删除。Alt + 左键拖动整条热键栏。
5. 通过模块设置修改名称、显示状态、隐藏空格、不透明度和缩放。悬浮热键栏不显示格内数字，设置页保留编号。

缩小布局只隐藏超出容量的格子，内容随角色配置保存，扩大后恢复；删除整栏会一并删除隐藏内容。开启“隐藏空格”后非空格子会紧凑排列，拖入时自动展开；需要保留中间空位时关闭该选项。

## 导入导出

“导出当前栏”或“导出全部设置”将 JSON 文本复制到剪贴板，可粘贴到文本文件保存。导入时复制完整文本，点击“从剪贴板导入…”，检查预览后确认追加。

导入生成新栏，不覆盖已有栏；自动生成内部身份，同名时加导入后缀。包括隐藏格、原生身份、指令、布局、外观与位置。全部设置还包含全局显示及操作说明选项，导入时可选择是否恢复。超过 12 栏上限时不能确认；游戏原生热键栏锁定时不能确认追加导入。

支持同模块跨角色分享，不包含角色身份；动作、宏、物品及套装能否使用仍取决于目标角色。仅接受 `NativeDragHotbar.Settings` 格式，不接受原有 `CustomHotbar` 导出格式。导入本身不会执行指令。

## 构建与验证

多文件源码放在 `Modules/NativeDragHotbar/`，通过独立工程编译为单个 DLL，不参与原有 `Tools/Validation` 的顶层单文件模块编译。DLL 不捆绑宿主公共依赖。

```powershell
# 默认使用已安装的 Omni 1.1.8.9 与 Dalamud Hooks dev。
dotnet build build/NativeDragHotbar/NativeDragHotbar.csproj -c Release
dotnet run --project tests/NativeDragHotbar.Tests/NativeDragHotbar.Tests.csproj -c Release

# 自定义构建依赖位置。
dotnet build build/NativeDragHotbar/NativeDragHotbar.csproj -c Release "-p:OmniDir=<Omni 版本目录>" "-p:DalamudDir=<Dalamud Hooks 目录>"
```

110 项独立离线检查覆盖布局扩缩、隐藏内容持久化、旧版迁移、跨角色导入、无效导入原子拒绝、原生身份与背包物品转换、拖放会话、指令插入、宿主契约及实际版本。独立测试中的宿主契约检查默认使用本机已安装的 Omni 1.1.8.9 / Dalamud Hooks dev。

原有 `Tools/Validation` 同时验证两个清单条目：源码按 Git LF 计算 SHA256，DLL 按原始字节计算，并检查 DLL 的模块契约、实际版本及各自本地化信息。
